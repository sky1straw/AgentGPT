# Finance Evaluator

This repository includes a standalone Python script `finance_evaluator.py` that provides a simple graphical interface for evaluating financial projects.

## Usage

1. Ensure Python 3 is installed on your system.
2. Run the script:

```bash
python3 finance_evaluator.py
```

3. Use the GUI to create projects, record inflows and outflows (with source/destination, date, and amount), and generate a report showing each project's total inflow, total outflow, net return, and ROI.
